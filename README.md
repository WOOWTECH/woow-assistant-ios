# 渥屋助理 iOS

獨立的 iOS 17+ 渥屋助理。此專案以 Mika／渥屋 Android 版作為**行為規格**，以 Swift 重建；不搬用 Android 的手機控制、無障礙、螢幕錄影或 ADB 能力。

## 目前狀態

這是開發中的版本，尚非完整助理。已加入可設定服務的實際模型對話、Keychain 金鑰、取消／錯誤後保留草稿，以及 MCP 私密端點設定與目錄探索。原生模型客戶端支援 JSON／SSE；目前對話畫面使用完整回覆，紀錄僅保留於本次程序。

MCP 可在連線後選取工具與資源，提供實際描述與參數規格給模型，由模型提出呼叫；每次須審核名稱與完整參數後執行。拒絕、取消、連線變更或逾時會停止，草稿與已收到結果保留；上限為 12 次模型決策、6 次操作、180 秒；模型指令格式最多修正一次，也計入相同額度，不會自動重送工具操作。記憶已加入本機加密儲存、手動管理、做法審核與回答後自動整理；Skills 支援全文匯入、待確認、試用／停用、修訂與文字參考。一般聊天成功不會自動被當成技能驗證成功。

已加入 WebKit 公開網站瀏覽、同站唯讀研究、獨立成果判定、完成任務後的技能草稿，以及有來源的網站知識與網頁路線。草稿需核准；重走路線會核對新頁面與原文，再判定回答是否完成要求。另支援逐次核准的 DOM 點擊、填字、選項與捲動，以及上一頁／下一頁／重新整理。

Mika 六項內建技能、三份支援檔與授權原文可搜尋閱讀；iOS 文字改寫先進入待確認，核准後為試用。文件技能新增系統選取 PDF、逐步核准讀取與 PDFKit 文字擷取。原版 Python PDF 腳本另有固定版本服務端與本機實測，尚未部署為 App 可用的遠端服務，詳見 [技能執行範圍](docs/SKILL_RUNTIME.md)。

技能編寫已有手動與模型入口：查詢既有技能、讀取原文、準備完整草稿，經使用者審閱核准後，以加密交易儲存為試用技能。實際模型編寫與重啟後讀回全文在 `6d480d8` 通過 1/1 介面案例。外觀設定的模型工具也已接入，須先允許本次設定修改；`2055c30` 的實際模型／暗色介面／重啟保存／撤銷權限案例通過 1/1。

文字整理接受使用者選取並核准讀取的 UTF-8 文字／字幕檔，或明確擷取的目前網頁文字快照；另須確認模型目的地才可開始。模型按範圍讀取來源，結果須覆蓋全部快照位元組且引文逐字符合來源。初版網頁擷取與實際模型流程通過 1/1；原生檔案流程及五種格式的真實模型測試仍有失敗，不能算全面完成。詳見[文字整理範圍](docs/CONTENT_TRANSCRIBE.md)。

瀏覽器支援分頁、加密書籤／歷史與重啟還原、持久 WebKit 網站資料及指定網站清除、手動登入、原生檔案選擇器，以及下載進度／取消／分享／刪除。SE 的工作區、登入、Cookie、網站資料清除與重啟矩陣在 `68c49a6` 通過 31/31；iOS 26.2 原生登入輸入修正於 `8ffc4d6` 通過 1/1。原生 FileProvider 選檔仍會間歇失敗，正在保留原始失敗並比較不同系統選檔入口。

Release 裝置編譯 `08fec36` 通過，建置編號 31、最低系統 iOS 17；產物尚未簽章，不能安裝。精確 iOS 17.0.1 的 `6d480d8` 通過核心 121/121、文件介面 7/7、MCP 測試伺服器介面 5/5，均零略過；其他介面分組仍有失敗或未執行，較新的功能需另行回歸。每輪來源、原始失敗與後續修正均列於[驗證紀錄](docs/VERIFICATION.md)，不以不同版本的局部成功組合成全面通過。真機、簽章及 TestFlight 條件見[發行紀錄](docs/IOS_DISTRIBUTION.md)。

尚未完整對齊 Mika：個人檔案整合、完整原版技能工具環境、遠端瀏覽器、各網站 OAuth／MFA／Passkey 相容性、聊天附件與通知仍未完成；本次新增功能的驗收依版本記錄，iOS 17 真機與簽章發行尚未驗證。詳細差異見 [記憶／Skills 對齊清單](docs/MEMORY_SKILLS_PARITY.md)。

「使用記憶」關閉後不讀取或自動整理記憶，但不刪除資料；已核准的 Skills 依各自開關啟停，與 Mika 相同。記憶／技能檔以 AES-GCM 加密，金鑰限本裝置 Keychain；目前不提供 iCloud 同步或備份還原。全部清除需要兩次確認，不會刪除模型與 MCP 憑證。

## 第一版目標範圍（尚未完成）

- 模型對話、串流任務狀態、記憶與附件。
- 受控的 MCP、Skills 與遠端計算工作。
- 內建 WebKit 瀏覽器：分頁、歷史、書籤、下載、上傳與頁面問答。
- 通知、語言／外觀與隱私設定。

不包含其他 App 操作、浮動膠囊、無障礙自動化、螢幕錄影、連接電腦控制、任意本機 Shell／Python／Node 執行。

## 本機開發

需要完整 Xcode 15+、Python 3 與 XcodeGen 2.44.1。CI 使用 Xcode 16.4／iOS 18.5 小、大螢幕，以及 Xcode 26.2／iOS 26.2；這不取代 iOS 17 真機驗證。

```sh
make project
make core-test
make test
```

`make test` 自動選擇本機已安裝且可用的 iOS 17+ iPhone 模擬器。只有 Command Line Tools 的主機可做部分 Swift 檢查，但無法建置或執行 iOS UI。CI 會保留測試日誌與 `.xcresult`，失敗時也會上傳。

手動 `Live model on iOS Simulator` 與 `Live HA MCP on iOS Simulator` 工作流程使用 GitHub Secrets 執行真實請求與 App UI 測試，不發布可能含憑證的附件。模型需設定 `WOOW_MODEL_TEST_API_KEY` secret，以及同名前綴的 `BASE_URL`、`MODEL` repository variables；HA 使用 `WOOW_HA_MCP_TEST_URL` secret。完整 Webhook URL 等同憑證，請勿提交到 repository、Issue 或公開日誌。HA 實測只使用明確審核的唯讀案例，不會依伺服器的 `readOnlyHint` 自動放行。

## 瀏覽器邊界

手動瀏覽使用公開 HTTPS 網址，接受一般查詢、片段與登入表單；網站 Cookie 由持久 WebKit 資料庫管理。書籤、分頁與歷史另外加密，已知 token／登入回呼網址不寫入這份資料。原生檔案選擇器只在使用者操作網頁時出現；下載沿用 WebKit 請求，不將 Cookie 複製到另一個下載客戶端。下載中離開 App 可能中斷，沒有背景完成保證。

研究模式保留較嚴格的公開頁面／同站連結限制，最多 12 次模型決策、180 秒；格式修正最多一次，也計入額度。單次 DOM 操作由模型提出、使用者核准後透過固定程式執行，不接受模型 JavaScript，也不開放密碼／檔案輸入。切換分頁會撤銷未完成提案；合成事件派送不代表網站任務成功。遠端 Browser Gateway、局域網政策及完整 Mika 瀏覽器相容性仍待完成。

網址政策只是字串與 IP 字面值的初步檢查，不是完整 SSRF 防線；接入網路時仍須檢查 DNS、重新導向與子資源。合約中的確認布林值也不是安全授權憑證。
