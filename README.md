# 渥屋助理 iOS

獨立的 iOS 17+ 渥屋助理。此專案以 Mika／渥屋 Android 版作為**行為規格**，以 Swift 重建；不搬用 Android 的手機控制、無障礙、螢幕錄影或 ADB 能力。

## 目前狀態

這是開發中的版本，尚非完整助理。已加入可設定服務的實際模型對話、Keychain 金鑰、取消／錯誤後保留草稿，以及 MCP 私密端點設定與目錄探索。原生模型客戶端支援 JSON／SSE；目前對話畫面使用完整回覆，紀錄僅保留於本次程序。

MCP 可在連線後選取工具與資源，提供實際描述與參數規格給模型，由模型提出呼叫；每次須審核名稱與完整參數後執行。拒絕、取消、連線變更或逾時會停止，草稿與已收到結果保留；上限為 12 次模型決策、6 次操作、180 秒；模型指令格式最多修正一次，也計入相同額度，不會自動重送工具操作。記憶已加入本機加密儲存、手動管理、做法審核與回答後自動整理；Skills 支援全文匯入、待確認、試用／停用、修訂與文字參考。一般聊天成功不會自動被當成技能驗證成功。

個人檔案新增手動編輯、替換／刪除歷史、加密保存與對話開始時的參考快照；一般聊天的模型提案、逐次審閱與保存流程正在驗收。主開關關閉後停止引用，完整清除會包含個人檔案。核心曾在三種模擬器與精確 iOS 17.0.1 通過；`856e8ec` 的 iOS 26.2 原生／hosted 測試通過 193/193（含 10 個個人檔案 App 整合方法），`dabe9bf` 實際模型回憶／關閉記憶流程通過 1/1；新版介面與新增工具另行重測；詳見[個人檔案範圍](docs/USER_PROFILE.md)。

## 本機開發

需要完整 Xcode 15+、Python 3 與 XcodeGen 2.44.1。CI 使用 Xcode 16.4／iOS 18.5 小、大螢幕，以及 Xcode 26.2／iOS 26.2；這不取代 iOS 17 真機驗證。

```sh
make project
make core-test
make test
```

`make test` 自動選擇本機已安裝且可用的 iOS 17+ iPhone 模擬器。只有 Command Line Tools 的主機可做部分 Swift 檢查，但無法建置或執行 iOS UI。CI 會保留測試日誌與 `.xcresult`，失敗時也會上傳。

手動 `Live model on iOS Simulator` 與 `Live HA MCP on iOS Simulator` 工作流程使用 GitHub Secrets 執行真實請求與 App UI 測試，不發布可能含憑證的附件。模型需設定 `WOOW_MODEL_TEST_API_KEY` secret，以及同名前綴的 `BASE_URL`、`MODEL` repository variables；HA 使用 `WOOW_HA_MCP_TEST_URL` secret。完整 Webhook URL 等同憑證，請勿提交到 repository、Issue 或公開日誌。HA 實測只使用明確審核的唯讀案例，不會依伺服器的 `readOnlyHint` 自動放行。

## 瀏覽器邊界

手動瀏覽使用公開 HTTPS 網址，接受一般查詢、片段與登入表單；網站 Cookie 由持久 WebKit 資料庫管理。書籤、分頁與歷史另外加密，已知 token／登入回呼網址不寫入這份資料。原生檔案選擇器只在使用者操作網頁時出現；下載沿用 WebKit 請求，不將 Cookie 複製到另一個下載客戶端。下載中離開 App 可能中斷，沒有背景完成保證。

研究模式保留較嚴格的公開頁面／同站連結限制，最多 12 次模型決策、180 秒；格式修正最多一次，也計入額度。單次 DOM 操作由模型提出、使用者核准後透過固定程式執行，不接受模型 JavaScript，也不開放密碼／檔案輸入。切換分頁會撤銷未完成提案；合成事件派送不代表網站任務成功。遠端 Browser Gateway、局域網政策及完整 Mika 瀏覽器相容性仍待完成。

網址政策只是字串與 IP 字面值的初步檢查，不是完整 SSRF 防線；接入網路時仍須檢查 DNS、重新導向與子資源。合約中的確認布林值也不是安全授權憑證。
